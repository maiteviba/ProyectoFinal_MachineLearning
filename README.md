# Proyecto Final: 

## Predicción del éxito académico en educación superior

Este repositorio contiene el código desarrollado para el proyecto final de la asignatura de Aprendizaje Automático de 2º iMAT.

1. Clasificación de la situación final del estudiante
2. Regresión para predecir la nota media del segundo semestre
3. Aprendizaje no supervisado para identificar perfilels de estudiantes


## Estructura del proyecto

Este proyecto está organizado en los siguientes notebooks:

- `limpieza_datos.ipynb`: limpieza inicial del dataset, revisión de variables, tratamiento de categorías y generación del dataset limpio
- `clasificacion.ipynb`: entrenamiento y evaluación del modelo de clasificación
- `regresion.ipynb`: entrenamiento y evaluación de modelos de regresión
- `no_supervisado.ipynb`: análisis no supervisado mediante PCA y clustering
- `memoria.pdf`: informe final del proyecto
- `README.md`: instrucciones para reproducir el trabajo


## Requisitos

Para ejecutar el código es necesario tener instalado Python 3 y las siguientes librerías:

pandas
numpy
matplotlib
seaborn
scikit-learn
